# Khoo Shi Xian — Portfolio

Minimal interactive portfolio. Static site, no build step — deploys straight to Vercel.

- `index.html` — content (hero, work explorer, brew log, trade, about, contact)
- `styles.css` — light/dark themes, per-section worlds, glide layout
- `script.js` — glide controller, canvases (nano, brew, ticks, work FX), explorer, brew log data
- `pfp.jpg` — profile photo

Add a coffee: append one line to `COFFEES` in `script.js` (name, origin, method, notes, rating 0–5).
